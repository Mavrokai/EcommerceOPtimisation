# Images Assets

Ce dossier contient les images utilisées par l'application e-commerce.

## Structure des images:

### Categories:

- `category-chiens.png` - Image pour la catégorie chiens
- `category-chats.png` - Image pour la catégorie chats
- `category-oiseaux.png` - Image pour la catégorie oiseaux

### Hero Banner:

- `hero-animals.jpg` - Image principale du hero banner

### Promotions:

- `promo-*.jpg` - Images pour les cartes promotionnelles

### Placeholder:

- `placeholder-category.png` - Image de remplacement pour les catégories
- `placeholder-product.png` - Image de remplacement pour les produits

## Format recommandé:

- Categories: PNG avec transparence, 400x300px
- Hero: JPG optimisé, 1920x800px
- Promotions: JPG optimisé, dimensions variables selon la taille
- Placeholders: PNG, 300x300px

## Optimisation:

- Compression WebP recommandée pour le web
- Formats de fallback en JPG/PNG
- Lazy loading implémenté dans le JavaScript
